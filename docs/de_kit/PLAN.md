## 3. Как запускать агентов параллельно

```bash
# один раз
cd parallax-dial && git pull
cp ~/de_kit/AGENTS.md . && echo '@AGENTS.md' > CLAUDE.md
mkdir -p pipeline && cp ~/de_kit/fields.yaml pipeline/fields.yaml
python -m venv .venv && source .venv/bin/activate

# отдельный worktree на каждую задачу
git worktree add ../pd-io     -b data/io
git worktree add ../pd-frame  -b data/frame
git worktree add ../pd-render -b data/render
# затем ../pd-pairs, ../pd-build, ../pd-moving, ../pd-dial

# в каждом окне терминала
cd ../pd-io && codex          # вставить текст prompts/01_io_search_download.md
cd ../pd-frame && claude      # вставить prompts/02_frame_reader.md
```
- **Codex** для чётко описанных модулей с тестами: P01, P03 (pairs.py), P04, P05 (код).
- **Claude Code** там, где нужно запускать, смотреть реальные FITS и разбирать ошибки: P00, P02, запуск PoC A, P05 (реальная сборка), P06, P07.
- **P08 QA** всегда в новой сессии, которая не писала этот код.
- Порядок слияния, чтобы не было конфликтов: P00 → P01 → P02 → P04 → P03 → P05 → P06 → P07. Общие файлы (`requirements.txt`, `pipeline/spx/__init__.py`) меняет только P00; остальным агентам запрещено.
- Выход PoC A и сборок проверяю глазами (`poc_a.png`, `contact.html`), а не только по зелёным тестам.
- Каждую задачу записываю в `docs/AI_USE.md` (одна строка: инструмент и что делал), это нужно для заявки.

## 5. Если что-то пошло не так

| Проблема | Действие (не больше 30 минут) |
|---|---|
| TAP не отвечает | `--method sia`; затем облачная копия (`cloud_access`, бакет `nasa-irsa-spherex`, s3fs anon); затем SPHEREx Data Explorer вручную, по 1 полю |
| Скачивание медленное | Только D2, `--limit 80`, равномерно по времени; запускать в фоне сразу после P01 |
| Мало честных пар (H1 не выполнена) | Порог 5% с честной меткой «medium»; добавить D1 и D3; для NEP взять `spherex_dr1_deep`/`spherex_qr3_deep` |
| В поле нет честных пар | Поле пишется только с naive-парами и предупреждением (по контракту клиент это объясняет) либо `enabled: false` |
| Нептун насыщен или замаскирован | Это ожидаемо; геометрия всё равно работает. Если совсем не виден, берём Уран (P06) |
| Go/No-Go №2 = нет | P07 не делаем; ручка расстояния идёт на слайд как модель. Время уходит на галерею и QA |
| IRSA упал вечером | Работаем из кэша: `build_all.py --offline` |
