Correlation used the grayscale PNGs, median subtraction, a 2-D Hann window, and the peak of `ifft2(fft2(A) * conj(fft2(B)))`; offsets above are integer `(x, y)` shifts. To reproduce a named pair, substitute its field and frame IDs:

  ```bash
  python3 - <<'PY'
  import numpy as np
  from PIL import Image
  field, a, b = 'm101', 'f047', 'f080'
  root = f'web/public/data/{field}'
  x, y = [np.asarray(Image.open(f'{root}/{name}.png').convert('L'), float) for name in (a, b)]
  x -= np.median(x); y -= np.median(y)
  window = np.outer(np.hanning(x.shape[0]), np.hanning(x.shape[1]))
  corr = np.fft.ifft2(np.fft.fft2(x * window) * np.conj(np.fft.fft2(y * window))).real
  iy, ix = np.unravel_index(np.argmax(corr), corr.shape)
  print(ix if ix <= x.shape[1] // 2 else ix - x.shape[1], iy if iy <= x.shape[0] // 2 else iy - x.shape[0])
  PY
  ```
